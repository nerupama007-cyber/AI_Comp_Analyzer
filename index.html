ABOUT PROJECT

About the Project

AI-Powered Customer Complaint Grammar Analyzer

This project combines Formal Language and Automata concepts with lightweight language-analysis techniques to analyze customer complaints.

The system demonstrates tokenization, formal grammar, DFA, PDA, stack operations and parse-tree generation. It also provides SLM-style and LLM-style complaint analysis for educational purposes.
